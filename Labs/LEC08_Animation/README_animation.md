# Drill #8 — Animation Viewer

## 구현 기준

- `animation_viewer.py`에서 Pico2D로 캐릭터를 화면 중앙에 표시한다.
- 대기, 걷기, 달리기, 점프를 순서대로 재생한다.
- 각 동작을 5회 재생한 뒤 마지막 자세에서 1초 멈춘다.
- 마지막 동작 다음에는 첫 동작으로 돌아가 무한 반복한다.
- 캐릭터는 화면 높이의 절반 이상으로 확대한다.
- 캐릭터 주변에 파티클, 잔상, 공격 궤적 등의 효과를 추가하지 않는다.

## 추가점수 목표

1. 프레임마다 다른 잘라내기 영역 `(x, y, width, height)`를 사용한다.
2. 동작별 프레임 수가 다른 시트를 지원한다: 대기 4, 걷기 6, 달리기 8, 점프 5.
